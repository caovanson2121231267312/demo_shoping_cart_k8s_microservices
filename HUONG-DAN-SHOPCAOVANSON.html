D. Chạy local trên Windows (nhanh nhất)

⚠️ Lưu ý PowerShell: Không dùng && và cp (Linux). Dùng lệnh PowerShell bên dưới.

D.1 Bật Docker Desktop

Mở Docker Desktop và đợi đến khi biểu tượng Docker ở taskbar hiện "Running". Nếu không bật, lệnh docker compose sẽ báo lỗi dockerDesktopLinuxEngine.

D.2 Chạy Auth Service

1

Copy file môi trường và khởi động stack Docker:

cd d:\k8s\shopcaovanson\services\auth-service
Copy-Item .env.example .env
docker compose up --build

Stack gồm: PostgreSQL, Redis, Kafka, Zookeeper, auth-service (port 8081).

2

Chạy migration (terminal mới, Docker đang chạy):

cd d:\k8s\shopcaovanson\services\auth-service
docker compose exec -T auth-service /app/migrate up
3

Seed dữ liệu mẫu (50 users):

$env:DATABASE_URL="postgres://auth:authpass@localhost:5432/authdb?sslmode=disable"
go run scripts/fake_data.go
4

Kiểm tra health:

Invoke-RestMethod http://localhost:8081/health

Kết quả mong đợi: {"status":"ok","service":"auth-service"}

D.3 Chạy Frontend

5

Tạo .env trỏ về API local (không dùng URL production):

cd d:\k8s\shopcaovanson\frontend\web
@"
NUXT_PUBLIC_API_URL=http://localhost:8081
NUXT_PUBLIC_WS_URL=ws://localhost:8081
NUXT_API_PROXY_TARGET=http://localhost:8081
"@ | Set-Content .env -Encoding UTF8
6
npm install
npm run dev

Mở trình duyệt: http://localhost:3000

✅ Đăng nhập admin: admin@shop.com / Admin@123
⚠️ Giới hạn local: Chỉ auth-service chạy → đăng nhập/đăng ký hoạt động. Danh sách sản phẩm, giỏ hàng, đặt hàng cần thêm product-service và order-service (xem mục E).

G. Tạo cluster Kubernetes trên VPS

Thực hiện trên VPS Ubuntu 22.04 (không phải Windows).

1

Clone repo

git clone https://github.com/caovanson/shopcaovanson.git
cd shopcaovanson
2

Tạo 3 VM bằng KVM (master + 2 worker)

sudo bash k8s/cluster-setup/setup-vms.sh
VMCPURAMDisk
master23 GB30 GB
worker-124 GB50 GB
worker-224 GB50 GB
3

Bootstrap master (kubeadm + Calico CNI)

sudo bash k8s/cluster-setup/bootstrap-master.sh

Script in ra lệnh kubeadm join — lưu lại file kubeadm-join.sh.

4

Join worker nodes

bash k8s/cluster-setup/bootstrap-worker.sh
5

Verify cluster

bash k8s/cluster-setup/verify-cluster.sh
# hoặc
make verify-cluster

Tất cả nodes phải Ready, system pods Running.

6

Copy kubeconfig về máy local (tùy chọn)

export KUBECONFIG=~/.kube/shopcaovanson-config
kubectl get nodes

H. Tạo Kubernetes Secrets

🔒 Quan trọng: Secrets không được commit vào git. Phải tạo thủ công trước khi deploy.

H.1 Secrets hạ tầng (namespace: infra)

kubectl create namespace infra

kubectl create secret generic postgres-secret -n infra \
  --from-literal=POSTGRES_PASSWORD='your-strong-postgres-password'

kubectl create secret generic mongodb-secret -n infra \
  --from-literal=MONGO_PASSWORD='your-strong-mongo-password'

kubectl create secret generic redis-secret -n infra \
  --from-literal=REDIS_PASSWORD='your-strong-redis-password'

kubectl create secret generic elasticsearch-secret -n infra \
  --from-literal=ELASTIC_PASSWORD='your-strong-elastic-password'

H.2 Secrets ứng dụng (namespace: shop)

kubectl create namespace shop

# Tạo cặp khóa RSA cho JWT
openssl genrsa -out jwt-private.pem 2048
openssl rsa -in jwt-private.pem -pubout -out jwt-public.pem

kubectl create secret generic auth-service-secret -n shop \
  --from-literal=DB_PASSWORD='your-strong-postgres-password' \
  --from-literal=REDIS_PASSWORD='your-strong-redis-password' \
  --from-file=JWT_PRIVATE_KEY=jwt-private.pem \
  --from-file=JWT_PUBLIC_KEY=jwt-public.pem

kubectl create secret generic api-gateway-secret -n shop \
  --from-literal=REDIS_PASSWORD='your-strong-redis-password' \
  --from-file=JWT_PUBLIC_KEY=jwt-public.pem

kubectl create secret generic product-service-secret -n shop \
  --from-literal=DB_PASSWORD='your-strong-postgres-password' \
  --from-literal=MONGO_PASSWORD='your-strong-mongo-password' \
  --from-literal=ELASTIC_PASSWORD='your-strong-elastic-password'

kubectl create secret generic order-service-secret -n shop \
  --from-literal=DB_PASSWORD='your-strong-postgres-password' \
  --from-literal=REDIS_PASSWORD='your-strong-redis-password'

kubectl create secret generic chat-service-secret -n shop \
  --from-literal=MONGO_PASSWORD='your-strong-mongo-password' \
  --from-literal=REDIS_PASSWORD='your-strong-redis-password' \
  --from-file=JWT_PUBLIC_KEY=jwt-public.pem

kubectl create secret generic notification-service-secret -n shop \
  --from-literal=SMTP_USER='your-smtp@gmail.com' \
  --from-literal=SMTP_PASSWORD='your-app-password'

kubectl create secret generic search-service-secret -n shop \
  --from-literal=ELASTIC_PASSWORD='your-strong-elastic-password'

rm -f jwt-private.pem jwt-public.pem

I. Deploy lên Kubernetes

1

Deploy toàn bộ (cert-manager + ingress + infra + apps)

make deploy-all
# hoặc
bash scripts/deploy-all.sh

Script tự động: cài cert-manager, nginx-ingress, kiểm tra secrets, apply manifests, chờ pods ready.

2

Deploy từng phần (nếu cần)

make deploy-cert-manager   # cert-manager + ClusterIssuer
make deploy-ingress        # nginx-ingress controller
make deploy-infra          # PostgreSQL, MongoDB, Redis, Kafka, ES
make deploy-services       # Tất cả microservices
make deploy-frontend       # NuxtJS frontend
3

Overlay Kustomize

# Production (mặc định)
kubectl apply -k k8s/overlays/prod

# Development (ít replica hơn)
OVERLAY=dev bash scripts/deploy-all.sh
4

Kiểm tra trạng thái

make status
kubectl get ingress -n shop
kubectl get certificates -n shop
kubectl describe certificate frontend-tls -n shop

O. Xử lý lỗi thường gặp

O.1 Docker không chạy (Windows)

failed to connect to the docker API at npipe:////./pipe/dockerDesktopLinuxEngine
→ Mở Docker Desktop và đợi daemon sẵn sàng.

O.2 PowerShell: && không hợp lệ

# Thay vì: cd x && cp y z
cd x; Copy-Item y z

O.3 Nuxt: "Another dev server is already running"

taskkill /PID <pid> /F
# hoặc
taskkill /F /IM node.exe
npm run dev

O.4 Pod Pending trên K8s

kubectl describe pod <pod-name> -n shop
kubectl get pvc -n infra

Thường do thiếu StorageClass hoặc RAM worker node không đủ.

O.5 SSL certificate không cấp được

kubectl describe certificate -n shop
kubectl logs -n cert-manager -l app=cert-manager

Kiểm tra DNS A record trỏ đúng IP và port 80 mở ra internet.

O.6 WebSocket chat không kết nối

kubectl get ingress shop-ingress -n shop -o yaml
kubectl get svc chat-service -n shop -o yaml

Đảm bảo ingress có annotation timeout 3600s và chat-service có sessionAffinity: ClientIP.

O.7 Migration thất bại

kubectl get jobs -n shop
kubectl logs job/migrate-auth-service-<timestamp> -n shop

Kiểm tra PostgreSQL đang chạy và secret auth-service-secret có DB_PASSWORD.

O.8 Worker không join được cluster

cat k8s/cluster-setup/kubeadm-join.sh
bash k8s/cluster-setup/bootstrap-worker.sh

Token join hết hạn sau 24h — chạy lại bootstrap-master.sh để tạo token mới.
