1b. Giải thích các thành phần cài đặt

Mỗi tab mô tả công dụng, phase cài, namespace và ai sử dụng trong hệ thống shopcaovanson.

Luồng request người dùng: Trình duyệt → DNS → MetalLB (IP 110.172.29.72) → nginx-ingress (HTTPS do cert-manager) → frontend (shopcaovanson.xyz) hoặc api-gateway (vocabee.cloud/api) → microservices → PostgreSQL / MongoDB / Redis / Kafka / Elasticsearch (namespace infra)

Ubuntu 22.04 LTS

Phase 1Hệ điều hành VPS

Nền tảng chạy toàn bộ cluster. Bản LTS được hỗ trợ bảo mật lâu dài, phù hợp production.

UFW (Firewall)

Phase 1OS

Chỉ mở port cần thiết: 22 (SSH), 80/443 (web), 6443 (K8s API). Chặn truy cập trái phép từ internet.

Fail2ban

Phase 1OS

Tự động chặn IP brute-force SSH sau nhiều lần đăng nhập sai — giảm nguy cơ bị scan/tấn công.

containerd

Phase 2Container runtime

Phần mềm thực sự chạy container (image Docker). Kubernetes gọi containerd để start/stop pod — không cần Docker daemon.

→ Mọi pod trong cluster

Helm 3

Phase 3Package manager

Cài các stack phức tạp bằng chart: cert-manager, nginx-ingress, kube-prometheus-stack — thay vì viết hàng trăm dòng YAML thủ công.

Kubernetes (kubeadm)

Phase 3Toàn cluster

Bộ não điều phối: schedule pod lên node, tự heal khi container chết, rolling update, service discovery nội bộ (*.svc.cluster.local).

Calico (CNI)

Phase 3kube-system

Mạng giữa các pod — mỗi pod có IP riêng, pod ở namespace khác nhau giao tiếp được. Hỗ trợ NetworkPolicy (cô lập infra/shop).

metrics-server

Phase 3.5kube-system

Thu thập CPU/RAM thực tế của pod và node → lệnh kubectl top và HPA (auto-scale api-gateway, product-service).

MetalLB

Phase 4metallb-system

Gán IP public 110.172.29.72 cho Service type LoadBalancer (nginx-ingress). VPS single-node không có cloud LB nên cần MetalLB.

→ ingress-nginx-controller nhận IP này

local-path-provisioner

Phase 4local-path-storage

Tạo ổ đĩa (PVC) cho StatefulSet: Postgres, MongoDB, Redis, Elasticsearch, Prometheus — lưu data trên disk VPS, không mất khi pod restart.

nginx-ingress

Phase 5 / deploy-allingress-nginx

Reverse proxy HTTP/HTTPS — nhận request từ internet, route theo domain/path: shopcaovanson.xyz → frontend, vocabee.cloud/api → api-gateway, /ws → chat WebSocket.

cert-manager

Phase 5 / deploy-allcert-manager

Tự động xin và gia hạn chứng chỉ SSL Let's Encrypt. Tạo Certificate resource → Secret TLS dùng cho Ingress.

ClusterIssuer (letsencrypt-prod)

Phase 5Cluster-wide

Cấu hình cert-manager dùng ACME production — cấp SSL hợp lệ cho shopcaovanson.xyz, vocabee.cloud, monitor.shopcaovanson.xyz.

Ingress (shop-ingress)

Phase 7namespace shop

Manifest định nghĩa rule routing + TLS + rate limit (50 req/s), force HTTPS, timeout WebSocket 3600s cho chat realtime.

PostgreSQL 15

Phase 7infra / postgres-0

Database quan hệ (SQL) — lưu user, sản phẩm, đơn hàng. Mỗi service dùng database riêng: auth_db, product_db, order_db.

→ auth, product, order services

MongoDB 7

Phase 7infra / mongodb-0

Database document (NoSQL) — linh hoạt schema cho catalog sản phẩm mở rộng và dữ liệu chat (phòng, tin nhắn).

→ product-service, chat-service

Redis 7

Phase 7infra / redis-0

Cache in-memory cực nhanh — session JWT blacklist, cache API, rate limit gateway, presence chat. Data có thể mất khi restart (chấp nhận được cho cache).

→ auth, api-gateway, order, chat

Elasticsearch

Phase 7infra / elasticsearch-0

Full-text search — index sản phẩm để tìm kiếm nhanh theo tên, mô tả, filter. Product service ghi index, search service đọc query.

→ product-service, search-service

Zookeeper + Kafka

Phase 7infra

Hàng đợi sự kiện (message broker) — giao tiếp bất đồng bộ: đặt hàng → gửi email, cập nhật tồn kho, analytics. Zookeeper điều phối Kafka cluster.

→ order, notification, analytics

frontend (Nuxt.js)

Phase 7shop

Giao diện web người dùng — trang chủ, sản phẩm, giỏ hàng, thanh toán. Gọi API qua https://vocabee.cloud/api (cross-origin).

→ https://shopcaovanson.xyz

api-gateway

Phase 7shop

Cổng vào duy nhất cho REST API — xác thực JWT, route tới microservice phía sau, CORS, rate limit Redis. Client không gọi thẳng từng service.

→ https://vocabee.cloud/api

auth-service

Phase 7shop · Go

Đăng ký, đăng nhập, JWT (RSA), refresh token, phân quyền user/admin. Lưu user trong PostgreSQL, session blacklist trong Redis.

product-service

Phase 7shop · Go

CRUD sản phẩm, danh mục, đánh giá. PostgreSQL + MongoDB + đồng bộ index Elasticsearch.

order-service

Phase 7shop · Go

Giỏ hàng, đặt hàng, thanh toán. Publish event Kafka khi order tạo → notification và các service khác xử lý.

chat-service

Phase 7shop · Python

Chat realtime WebSocket — phòng chat buyer/seller, lưu tin nhắn MongoDB, presence Redis.

→ wss://vocabee.cloud/ws

notification-service

Phase 7shop · Python

Gửi email SMTP (xác nhận đơn, reset password) — consume event từ Kafka. Cần cấu hình SMTP trong secret.

search-service

Phase 7shop · Python

API tìm kiếm sản phẩm — query Elasticsearch, trả kết quả có phân trang và filter.

analytics-service

Phase 7.4shop · Python

Báo cáo admin (doanh thu, users, reviews), online users, xuất Excel đơn hàng async. Đọc 3 DB Postgres + Redis + Kafka.

→ /admin/reports · /admin/orders (Xuất Excel)

rasa-service

Phase 7.4shop · Python

Chatbot AI — bridge tới Rasa ML (tùy chọn) hoặc bot_engine fallback. Gợi ý sản phẩm, tra cứu đơn.

→ /api/chatbot/message

Kubernetes Secrets

Phase 6infra + shop

Lưu mật khẩu DB, JWT keys, SMTP, GHCR — inject vào pod qua env/volume. Tách biệt khỏi git và ConfigMap (ConfigMap không mã hóa).

→ bash scripts/create-secrets.sh

ConfigMap

Phase 7shop

Cấu hình không nhạy cảm: host DB, port, tên database, CORS domain, URL API frontend. Thay đổi ConfigMap + restart pod để cập nhật.

NetworkPolicy

Mục 14infra + shop

Firewall nội bộ cluster — infra chỉ nhận kết nối từ shop; chỉ ingress-nginx gọi được frontend/api/chat; notification được egress SMTP ra internet.

→ bash scripts/apply-security.sh

Pod Security Standards

Mục 14infra + shop

Chính sách bảo mật pod: cấm privileged container, hạn chế leo quyền — giảm rủi ro nếu app bị khai thác.

GitHub Actions + GHCR
