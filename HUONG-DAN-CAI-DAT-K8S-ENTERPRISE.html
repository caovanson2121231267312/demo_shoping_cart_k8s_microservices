2.2 Cấu hình containerd (SystemdCgroup = true)

🎯 Mục đích: Đồng bộ cgroup với systemd — kubelet yêu cầu cấu hình này trên Ubuntu 22.04.

⚠️ Bỏ qua bước này: Pod sẽ CrashLoop hoặc kubelet báo lỗi cgroup driver.

sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
sudo systemctl restart containerd
sudo systemctl enable containerd

6.3 Tạo secrets ứng dụng + JWT keys (namespace: shop)

🎯 Mục đích: Cấp DB password, Redis password, cặp khóa RSA JWT cho auth-service và api-gateway.

kubectl create namespace shop

openssl genrsa -out jwt-private.pem 2048
openssl rsa -in jwt-private.pem -pubout -out jwt-public.pem

kubectl create secret generic auth-service-secret -n shop \
  --from-literal=DB_PASSWORD="$PG_PASS" \
  --from-literal=REDIS_PASSWORD="$REDIS_PASS" \
  --from-file=JWT_PRIVATE_KEY=jwt-private.pem \
  --from-file=JWT_PUBLIC_KEY=jwt-public.pem

kubectl create secret generic api-gateway-secret -n shop \
  --from-literal=REDIS_PASSWORD="$REDIS_PASS" \
  --from-file=JWT_PUBLIC_KEY=jwt-public.pem

kubectl create secret generic product-service-secret -n shop \
  --from-literal=DB_PASSWORD="$PG_PASS" \
  --from-literal=MONGO_PASSWORD="$MONGO_PASS" \
  --from-literal=ELASTIC_PASSWORD="$ES_PASS"

kubectl create secret generic order-service-secret -n shop \

12.1 Tắt đăng nhập SSH bằng mật khẩu BẮT BUỘC

🎯 Mục đích: Chỉ cho phép SSH bằng private key — chặn brute-force password trên port 22.

⚠️ Cảnh báo: Đảm bảo SSH key đã copy lên VPS trước khi chạy, nếu không sẽ bị khóa ngoài.

📍 Chạy tại: VPS 110.172.29.72

# Kiểm tra đã có SSH key chưa
grep -c "ssh-" ~/.ssh/authorized_keys

# Hardening sshd
sudo sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -i 's/^#*PermitRootLogin.*/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
sudo sed -i 's/^#*PubkeyAuthentication.*/PubkeyAuthentication yes/' /etc/ssh/sshd_config
sudo sed -i 's/^#*X11Forwarding.*/X11Forwarding no/' /etc/ssh/sshd_config
sudo sed -i 's/^#*MaxAuthTries.*/MaxAuthTries 3/' /etc/ssh/sshd_config
sudo systemctl restart sshd

12.2 Giới hạn K8s API (port 6443) theo IP CAO

🎯 Mục đích: Port 6443 (Kubernetes API) không nên mở toàn internet — chỉ cho IP máy admin remote kubectl.

📋 Thay YOUR_HOME_IP bằng IP public máy bạn (tra tại whatismyip.com).

# Xóa rule mở 6443 cho mọi người (nếu đã tạo ở Phase 1)
sudo ufw delete allow 6443/tcp

# Chỉ cho phép IP admin (thay YOUR_HOME_IP)
sudo ufw allow from YOUR_HOME_IP to any port 6443 proto tcp comment 'K8s API admin only'
sudo ufw status numbered

12.7 Mã hóa backup PostgreSQL CAO

🎯 Mục đích: Backup DB được nén + mã hóa GPG — nếu file backup bị lộ vẫn không đọc được dữ liệu.

# Tạo khóa GPG (chỉ chạy 1 lần, lưu passphrase an toàn)
gpg --batch --passphrase "$(openssl rand -base64 24)" \
  --quick-gen-key "backup@shopcaovanson.xyz" default default

# Backup mã hóa hàng ngày
BACKUP_DIR="/var/backups/k8s/postgres"
mkdir -p "$BACKUP_DIR"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
kubectl exec -n infra postgres-0 -- pg_dump -U shopcaovanson shopcaovanson \
  | gzip | gpg --encrypt --recipient backup@shopcaovanson.xyz \
  > "$BACKUP_DIR/shop_${TIMESTAMP}.sql.gz.gpg"
ls -lh "$BACKUP_DIR" | tail -3
Mở rộng — Kết quả dự kiến
